# Beer Game

MIT Sloanで考案されたサプライチェーン管理シミュレーション「ビールゲーム」のWebアプリ実装です。
小売・二次卸・一次卸・工場の4段階からなるサプライチェーンで在庫と発注を管理し、需要変動が上流ほど増幅される「ブルウィップ効果」を体験・学習できます。

## 現在のスコープ（Phase 1）

- シングルプレイヤー（人間1役割 + ルールベースAI3役割）
- 顧客需要の急増シナリオ（4個/週 → 8個/週）によるブルウィップ効果の再現
- ゲーム終了後の振り返り画面での全役割推移の可視化

マルチプレイヤー（複数人がリアルタイムで別々の役割を担当）はPhase 2として今後追加予定です。

## ルール概要

- 役割（上流→下流）: 工場 → 一次卸 → 二次卸 → 小売 → 顧客
- 出荷・発注リードタイム: 各2週間
- コスト: 在庫保管 0.5ドル/ユニット/週、欠品（受注残） 1.0ドル/ユニット/週
- 各週の処理順序: 入荷 → 受注確認 → 出荷（不足分は受注残） → コスト加算 → 発注

## アーキテクチャ

- バックエンド: Python + FastAPI（`backend/`）。ゲームロジックはpure functionによる functional core（`backend/app/core/`）と、永続化・APIを担うimperative shell（`backend/app/store/`, `backend/app/api/`）に分離。
- フロントエンド: TypeScript + React + Vite（`frontend/`）
